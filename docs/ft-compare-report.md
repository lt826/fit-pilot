## 2×2 因子分解（本实验的核心产出）

| 效应 | 幅度 | 解读 |
|---|---|---|
| 检索的效应（无微调 A→D） | **+10.4 点** | RAG 把正确率顶到 96%+，拒答 75→100 |
| 检索的效应（有微调 B→C） | **+26.3 点** | 对被微调"带偏"的模型，检索的矫正更大 |
| 微调的效应（无检索 A→B） | **−16.8 点** | 小数据 LoRA 单独使用显著有害：数字靠回忆出错 + 拒答边界 75%→20% |
| 微调的效应（有检索 D→C） | **−0.9 点（噪声内）** | 检索之上微调无显著增量；误拒略优（3.5% vs 5.2%） |

**结论：在本任务上，微调没有在任何配置下产生显著正贡献——正确率与拒答防线的收益全部来自检索。** "微调塑风格、检索供事实"在四组全因子下成立：微调唯一可量化的收益是口吻与误拒率的边际改善。

## 双防线拒答的机制分析

- 两个 RAG 组的 60 道拒答题**全部被第一道防线（检索相关度闸门，top1 < 0.61）拦截**，生成层未被考验——向量分数对域外题（含口语化域外题）分离度良好
- 微调对模型自身边界感的破坏（B 组拒答 75%→20%）在有闸门的配置下被完全补偿（C 组 100%）——**机制性防线比模型秉性可靠**
- 口语化拒答题（40 条）与书面题行为一致，闸门对问法变化鲁棒

## 口语化问法的鲁棒性（v2 新增维度）

| 组 | 书面题 | 口语化题 |
|---|---|---|
| A 基座直答 | 85.4% | 87.0% |
| B LoRA 直答 | 69.2% | 69.2% |
| D 基座 + RAG | 96.3% | 96.5% |
| C LoRA + RAG | 95.3% | 95.8% |

四组的口语/书面差异均在 ±2 点内——**混合检索与生成对问法口语化不敏感**，v1 时代"自动生成题偏向标题重合"的担忧被口语化变体的实测打消。

## 意外消融：检索降级到 BM25 单路时的表现

首轮 C/D 组运行时 Qdrant 意外停机，检索全程静默降级为 BM25 单路（814 次，已被断点机制隔离重跑）。这组"意外消融"数据（备份于 `data/eval/_ft_bmj25_only意外消融备份.jsonl`）显示：D' 94.6%、C' 91.6%，正确率仅降 1~4 点，但 **C' 拒答率跌至 48.3%**（闸门依赖向量分数，降级即失效，拒答只剩生成层一道）——印证了双防线中第一道的不可替代性，也说明降级机制保住了可用性却改变了对齐实验条件（评测必须在组件健康下运行，见 dev-log）。

## 与 v1（2026-10-31，221 题×3 组）的对照

v1 结论（LoRA+RAG 96.9% > 基座 87.9% > LoRA 66.2%）方向与 v2 一致；v2 补上第四组后，"检索之上微调还有没有增量"这一定量问题得到回答（−0.9 点，噪声内）。v1 的 96.9% 与 v2 的 95.5% 差异来自题集扩容（221→407）与口语化题占比。
