# 面试追问预备（高频五问，一句话版）

1. **为什么手写工具循环不用 LangChain Agent？** 循环核心只有几十行，手写能完全掌控结果回填、错误反馈和轮数熔断，也让我真正讲得清 FC 机制。
2. **闸门阈值 0.61 怎么定的？** 用真实问答跑分数分布标定：知识题与域外题的相关度分界带在 0.54~0.61 之间，取分离度最好的点；换 embedding 模型后重新标定过一次（0.45→0.61）。
3. **微调为什么没用？** 2×2 实验显示微调在检索之上无显著增量、单独使用反降 16.8 点；3B 底座预训练见过海量健身语料，791 条小数据 LoRA 撬不动，还丢了拒答边界感。
4. **混合检索比单路向量好在哪？** 术语/关键词类查询 BM25 救向量，语义改写类查询向量救 BM25；RRF 只用排名融合，免疫两套分数量纲不可比的问题。
5. **生产化怎么考虑？** 单用户版边界明确：会话缓存在单进程内存，多 worker 换 Redis；生产同源部署单 uvicorn 进程，已在阿里云公网验证。
